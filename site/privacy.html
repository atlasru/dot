PRIVACY

Nothing to profile.

01

Website

The dot. website does not include analytics, advertising pixels, account systems or telemetry scripts.

02

Network status

The network-status card requests public IP metadata from ipwho.is directly from your browser. That request is made to the third-party service, not to a dot. backend. dot. does not operate a server that receives or stores the lookup result.

You can leave the site without using the card, and a failed lookup does not affect any other part of the website.

03

GitHub releases

The website requests the public GitHub Releases API to discover the current Android and Windows download assets, versions, file sizes and SHA-256 digests. Download buttons point to GitHub release assets.

04

Client

dot. is a VPN client, not a VPN provider. It does not provide accounts or operate VPN servers. You bring your own compatible VLESS subscription.

05

Subscription credentials

Subscription URLs and VLESS links can contain credentials such as tokens and user IDs. Treat those values like passwords. User-facing refresh diagnostics redact sensitive VLESS information before raw errors reach the UI.

06

Node geolocation

The client can resolve node IP addresses for map placement. Subscription URLs, UUIDs and VLESS credentials are not included in geolocation requests.
