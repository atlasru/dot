FAQ

Short answers.

What is dot.?

An open-source VPN client for Android and Windows with VLESS, Hysteria 2, subscriptions, node testing, map view and a minimal interface.

Does dot. provide VPN servers?

No. dot. is a client. You need your own compatible VLESS or Hysteria 2 subscription.

Which transports are supported?

Android and Windows support VLESS and Hysteria 2 subscriptions through Xray/libXray.

Why is the Windows build unsigned?

The Windows executable is unsigned. Extract the complete portable ZIP, including its runtime folder. Microsoft Edge WebView2 Runtime is required.

Does the website track visitors?

No analytics or advertising scripts are included. The network-status card requests public IP metadata directly from a third-party service when the page loads or you refresh the card.
