FAQ

Short answers.

What is dot.?

An open-source VLESS client for Android and Windows built around subscriptions, node testing, map view and a minimal interface.

Does dot. provide VPN servers?

No. dot. is a client. You need your own compatible VLESS subscription.

Which transports are supported?

The current Android release focuses on VLESS with REALITY and TLS through Xray-core.

Why is the Windows build unsigned?

The desktop client is still an alpha build and the current Windows executable has not been code-signed yet.

Does the website track visitors?

No analytics or advertising scripts are included. The network-status card optionally requests your public IP metadata from a third-party lookup service in your browser.
