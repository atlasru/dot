# dot. v0.3.0

Unified Android and Windows milestone with Orb-based connection controls and improved node and subscription management.

## Android

- Home / Nodes / Settings workflow with floating navigation and Orb connection control.
- Per-app split tunneling: all apps, exclude selected, or only selected apps.
- One-shot AUTO NODE chooses the fastest successful URL-tested node.
- Network-aware reconnect, waiting/reconnecting states, capped 1/2/5/10/30-second backoff and classified VPN failure diagnostics.
- Node map, per-subscription sorting, individual/group URL tests and live node switching.
- Subscription refresh summaries, redacted errors and preservation of existing nodes after failed updates.

## Windows

- Unified workspace; Home Orb connects, disconnects and cancels startup.
- Add/edit/delete subscriptions and import VLESS links or text files.
- Safe subscription refresh preserves data on fetch/write failures, with optional startup and scheduled refresh active in the tray.
- Search, persistent favorites, sorting, individual/batch URL tests and map/GeoIP views.
- Tray controls, interface traffic information and controlled live node switching.
- Guards against overlapping connection/test operations, pinned Xray configuration validation, process-tree ownership and exit watchdog.

## Requirements / Notes

- Android 8.0+ (API 26). Source version 0.3.0 / versionCode 300.
- Android download is the established **debug variant**, versionName `0.3.0-debug`, application ID `dev.dotclient.android.debug`, signed with the repository's **public development key**. It is debuggable and is **not production-signed**. It can update compatible earlier builds signed with that same development key. No private production signing configuration is available in the repository.
- Windows x64 portable ZIP: extract the entire archive, keep `runtime/` alongside `dot-desktop.exe`, and run the executable. Microsoft Edge WebView2 Runtime and administrator privileges for TUN/routing are required.
- Windows executable is a release-mode build and **unsigned**. Windows may show an unknown-publisher warning. No installer is included; the existing NSIS configuration has not been validated as a release installer.
- Xray-core / libXray v26.7.28; Windows Xray and Wintun are bundled.
- Desktop automatic reconnect, AUTO NODE, split tunneling and kill switch are not implemented.
- No accounts, ads, analytics or telemetry in the clients. Map/GeoIP and connectivity tests contact external services.
