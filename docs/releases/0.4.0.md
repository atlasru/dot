### Source provenance and Hysteria2 hotfix

The **original release tag** `v0.4.0` still points to source commit `52a7dd01b989b26047fa3d36ef08ff3cab795945`. The downloadable release assets **do not correspond to that original tag snapshot**: they were replaced on 18 October 2026 by the passing [unified Actions run #39111580483](https://github.com/atlasru/dot/actions/runs/39111580483) from commit [`9d7064c3fd83f340f787e6656c2d6f0c915cfcce`](https://github.com/atlasru/dot/commit/9d7064c3fd83f340f787e6656c2d6f0c915cfcce). This fixed Hysteria2 Xray routing and Salamander packet-size output. The published files and their checksums were verified after replacement. **Do not assume checking out `v0.4.0` recreates the patched release binaries.**

## What's new

- Support `vless://`, `hy2://` and `hysteria2://` links; load VLESS-only, Hysteria2-only and mixed subscription groups.
- Hysteria2 TLS, SNI, ALPN, configurable congestion, optional Salamander obfuscation and packet-size parameters.
- Persistent independent X-HWID per subscription with copy, edit, paste and confirmed regeneration. The value is sent with subscription HTTP requests, not VPN traffic; redirects crossing origins strip identity headers.
- Upgrade 0.3.0 subscriptions, node credentials, selection and relevant preferences without reimporting.
- Maintain Xray/libXray **v26.7.28**. Hysteria 1 and non-Salamander finalmask types are not supported.

- This is **not** Play Store/production-signed software. A different application ID or signing key cannot be silently upgraded in place.

## Windows version and upgrade

- Version `0.4.0`. Portable ZIP contains unsigned `dot-desktop.exe`, `runtime/xray.exe`, `runtime/wintun.dll` and `BUILD.json`.
- Extract the **entire ZIP** together. Install Edge WebView2 Runtime if missing and start with administrator rights to configure VPN routing.
- Persistent state from 0.3.0 is migrated; preserve backups of critical configuration. No validated installer is included.
