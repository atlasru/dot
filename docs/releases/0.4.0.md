# dot. v0.4.0 development candidate

This is a build candidate for protocol and migration testing. It is **not a stable release**. Do not publish or deploy it to existing users until the manual checks in `docs/hysteria2-manual-test.md` pass with real provider nodes.

## Changes under test

- Android and Windows accept `hy2://` and `hysteria2://` alongside VLESS in mixed subscriptions and imports.
- Xray-native Hysteria version 2 outbound supports TLS, SNI, ALPN, congestion and optional Salamander finalmask with configurable password and packet size.
- Protocol badges, logical refresh matching, credential redaction and backward-compatible v0.3.0 state loading.
- Xray/libXray stays at v26.7.28. Hysteria v1 and other finalmask types are unsupported.

## Validation boundary

- Windows CI checks generated VLESS and HY2 configs with pinned Xray and builds the portable package.
- Android CI builds the development-key debug APK and runs unit tests. Real libXray VPN/QUIC operation requires a device.
- Provider-specific links, network handoff, bad-auth/SNI and UDP-blocked scenarios remain pending manual validation.
