# dot. 0.5.0

- Added categorized advanced settings on Android and Windows, preserving the existing themes, subscriptions and minimal dark interface.
- **Android Motion:** animated VPN orb states, tab transitions, node reordering and diagnostic results, settings controls and dialogs.
- Added Via Proxy GET/HEAD, direct TCP and actual system ICMP diagnostics with validated URL, timeout, attempts, aggregation, bounded concurrency, scheduling, cancellation and cache reset.
- Default: GET `https://cp.cloudflare.com/generate_204`, 5 seconds, 3 attempts, median, 4 parallel nodes, startup testing off.
- Separated network timing from config and core startup. Android runs diagnostic cores in a separate process, distinguishes unavailable nodes from confirmed failures, and checks the connected node through a temporary proxy configured for that session. VPN recovery follows changes to the underlying network.
- **Windows diagnostics:** URL TEST measures the selected node using the configured method. Proxy checks use a separate Xray process bound to the underlying network. Test All reports progress and per-node results as they arrive and retains completed results on cancellation.
- Stored typed diagnostic metadata and prevented incompatible results from affecting sorting/AUTO. TCP/ICMP alone never verify a proxy; TCP is rejected for HY2.
- Added conservative verified-proxy AUTO on Windows and aligned Android eligibility, node exclusions and latency thresholds. Manual selection disables AUTO.
- Added numeric DNS, private-address bypass, subscription request controls and redacted diagnostic metric/settings export/import/reset. Android also exposes its reconnect policy and scheduled subscription refresh.
- **HY2 fix:** includes Android commit `852e5a7`; HY2 displays `HY2 · tls · udp`. Windows protocol-aware display also reports UDP for legacy stored HY2 nodes. VLESS transports are preserved.
- Android versionName 0.5.0, versionCode 500; Windows/Tauri 0.5.0. Pinned Xray/libXray stays v26.7.28.
- Removed automatic main-branch release promotion. Actions builds versioned candidate artifacts; publishing requires a separate explicitly approved tag workflow dispatch.
- Updated frontend build tooling to Vite 8.1.6 and source-map-js 1.2.2 to close the npm audit findings; VPN core dependencies are unchanged.

See [diagnostic semantics, platform limitations and validation requirements](../DIAGNOSTICS.md). TCP/ICMP measure server reachability, while GET/HEAD measure an actual proxied HTTP operation; their values should not be compared as the same metric. HTTP 405 on HEAD means the test URL does not support HEAD.

CI compilation, unit tests and config checks are not evidence of real provider VPN operation. Device/provider validation remains required before publication. APKs use stable development signing; Windows portable executables are unsigned. Existing 0.3.0 and 0.4.0 releases/assets are retained.
